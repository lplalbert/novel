## 记忆残片机制（**新的爽点 + 伏笔工具**）

| 项 | 设定 |
|---|---|
| **是什么** | 麻醉梦境里经历的残留，被「封存」了大部分 |
| **怎么触发** | 关键时刻（决赛、抉择、遇险）闪回 |
| **闪回什么** | **碎片**：一个画面、一句话、一种感觉。不给完整信息 |
| **持续多久** | 一两秒，然后散掉 |
| **用法 1（爽点）** | 闪回让他做出正确决策（"我好像见过这一幕"） |
| **用法 2（伏笔）** | 闪回内容是后续剧情的预告 |
| **用法 3（悬念）** | 为什么记不清？系统故意？大脑保护？还是别的？ |
| **频率** | 每 20-30 章一次，不要频繁（频繁就廉价了） |
