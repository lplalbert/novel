## 0. 三条修正（已记入设定）

1. **主角不绑 AI 博士**。作者的科技/金融背景只用来把行业内容写真，不硬塞进人设。
2. **系统为主**，能力**由任务解锁**，不是开局送满。
3. **扩展走「跨域跳跃」，不走「同域放大」**。
   - ✅ 游戏 → 预测 → 金融量化 → 决策公司（能力在变形）
   - ✅ 电竞 → AI 训练体系 → 反哺学术（副线）
   - ❌ 夺冠 → 电竞数据公司 → 科技创业（同一件事做更大）
   - ❌ 网吧队 → 俱乐部 → 训练营（同上）

## 1. 主角（人设方向，细节等人物卡）

**不写 AI 博士**，写一个**现实不得志、但脑子好使的普通人**：

- **身份**：普通本科毕业，游戏打得极好，现实不顺（失业 / 考研考公失利 / 小职员被裁）
- **底色**：逻辑强、观察细、抗压、嘴硬心软
- **为什么这样设计**：
  - 开局低谷，反差大，番茄读者代入感强
  - 「脑子好使」能解释他**怎么用系统**——不是无脑开挂，是会算、会藏、会布局
  - 后期做金融量化时，可以走「自学/进修/被高人带」的合理化路径，用上你熟悉的行业细节

## 2. 系统设计（本书的地基，必须自洽）

### 2.1 系统名（暂定）

**「弈局系统」**（可改）

### 2.2 来源：**麻醉梦境**（已定，全书最大伏笔）

**手术麻醉中，意识进入某种状态，系统出现，给他任务，梦中时间飞速，他一路打到世界冠军。醒来后记忆大部分残缺。**

```
麻醉（意识改变状态）
   ↓
进入「梦境」= 系统的接入通道 / 训练场
   ↓
系统出现，给任务
   ↓
梦中时间飞速：一路赢到世界冠军（碎片记忆）
   ↓
醒来，记忆残缺
   ↓
打开金铲铲，发现和梦里一样
```

**为什么这个设计好**：
1. **仪式感**：麻醉/濒死 = 意识改变状态 = 接入条件，比"突然绑定"合理
2. **长期期待提前立住**：读者第 3 章就知道他会拿世界冠军（梦里的画面）
3. **多一条伏笔线**：记忆残片回收，每 20-30 章闪回一次
4. **悬念双用**：梦里的冠军是真的吗？为什么记不清？系统为什么不给完整记忆？

**深层真相（卷 6 揭示，暂定）**：
- 麻醉梦不是普通的梦，是**系统的接入仪式**
- 梦里的世界冠军是**真的**（或者是某种「预演」/前代宿主的经历）
- 记忆残缺是**系统故意的**——完整记忆会让宿主崩溃 / 或者是某种保护
- **和血脉呼应**：陈家男性的遗传病是「命运线的标记」，手术+麻醉是**接入条件**
- **和前代宿主呼应**：「你不是第一个」——太爷爷那一支的人，都被接入过

**备选深层设定**（等你定）：
| 方向 | 内容 |
|---|---|
| A 命运漏洞 | 世界的「概率」有 bug，他是能看见 bug 的人 |
| D 前代宿主传承 | 系统有历史，前代宿主下场不明 |
| **D+A（建议）** | 传承 + 漏洞，留白最多 |

### 2.3 能力体系：**任务解锁制**

> 设计原则：**金手指刚好解决当前矛盾 → 暴露更大矛盾**。
> 每个能力解锁都是一个**剧情节点**，不是白送。

| 等级 | 能力 | 解锁时机 | 代价 / 限制（**不能省**） |
|---|---|---|---|
| **T1 透视** | ① 透视牌库（剩余卡池）<br>② 透视下一轮海克斯选项<br>③ 透视未来装备散件 | 开局 / 初期任务 | 精神消耗大，有时间窗口；只能看到「下一档」信息 |
| **T2 影响** | ① 控制牌库（伪随机微调，不是无中生有）<br>② **弈子状态控制：假赛 / 超常发挥** | 中期任务 | 次数严格受限；**每次改动会在「命运线」上留痕** |
| **T3 预测** | ① 预测对手阵容走向<br>② 预测比赛结果<br>③ **跨界预测现实事件** | 中后期任务 | 越远越模糊；强行看清会反噬（运气/健康） |
| **T4 干预** | 直接干预现实事件 | 最终卷 | 代价最大，全书最高潮 |

### 2.4 关于「假赛 / 超常发挥」（你提的最有意思的一点）

这个能力的妙处在于**有战术价值 + 有道德灰度**：

- **假赛不是无脑放水**，而是：
  - 维持**连败吃利息**（这是云顶真实战术，懂的读者会心一笑）
  - 藏拙，诱对手上钩
  - 关键局突然「正常发挥」打崩对手心态
- **超常发挥**不是「必赢」，是「把这波打赢的概率从 40% 提到 70%」——**还是有翻车可能**，这才叫符合逻辑
- **道德代价**：假赛留下的「命运线痕迹」是后期的大伏笔

### 2.5 任务体系

| 任务类型 | 例子 | 作用 |
|---|---|---|
| **游戏任务** | 用冷门羁绊吃鸡 / 三星五费 / 连胜 15 / 不用某类卡进前二 | 推动游戏线剧情 |
| **现实任务** | 帮某人解决一个困境 / 拒绝一次不义之财 / 公开承认一次错误 | 推动现实线剧情 + **爽点元素的来路** |
| **隐藏任务** | 触发条件不明，奖励丰厚 | **伏笔专用**，回收时给读者「原来如此」 |

**任务失败惩罚**（不是死亡，太廉价）：
- 能力降级 / 临时封印 / 一段时间内反噬
- 失败本身往往**产生更好的剧情**（走投无路 → 被迫成长）

### 2.6 代价体系（**逻辑自洽的关键，一条都不能少**）

1. **使用次数/精力**：不是无限用，每天/每局有上限
2. **命运线痕迹**：改牌库、假赛都会留下痕迹 → 被某种存在/人察觉
3. **运气守恒**：能力用多了，主角自己的「运气」变差（生活里的小倒霉）
4. **被观测风险**：用得太离谱会被当成「开挂」「怪物」→ 必须表演、找借口、低调
5. **反噬**：强行看太远的未来，身体/精神受损

## 4. 扩展路径（按你的评价重构）

### 主线：游戏 → 预测 → 金融量化 → 决策公司

关键在于**能力在变形**，不是同一件事做更大：

```
游戏里：能看见牌库 → 能预测对手走向 → 能预测比赛结果
                ↓（能力跨界）
现实中：能预测人的决定 → 能预测市场波动 → 能预测行业趋势
                ↓（能力变现）
商业上：预测咨询 → 金融量化 → 决策公司
```

**每一次「跨界」都是一个转折点**，不是时间推移的自然结果。

### 副线：电竞 → AI 训练体系 → 反哺学术

**作为副线/支线**，不占主线：
- 卷 3-4 之间，主角用数据思维做对手研究 → 引出「电竞 AI 训练」概念
- 卷 5 之后，这条线成为决策公司的技术底座
- 结局可以是他把这套东西反哺回学术/行业

## 5. 爽点元素怎么落（**有机，不硬塞**）

| 元素 | 怎么来 | **为什么合理**（不许省这一栏） |
|---|---|---|
| **美女** | 三选一或组合：<br>① 豪门千金（家族想请他做预测顾问）<br>② 对手战队女分析师（亦敌亦友）<br>③ 直播搭档（搭档→感情） | **不是花瓶**。她有自己的欲望、能力、困境。因为**认可他的能力**、和他**共同经历过事**才靠近。**绝不无脑倒贴** |
| **豪车** | 世界赛奖金 + 第一笔预测咨询费 | 有来路、有税务/合规描写。「第一次坐进自己买的车」是仪式感场景，不是天上掉的 |
| **豪宅** | 卷 3 财务自由后的自住/工作室 | 用它做**剧情场景**（拜师宴、对峙、告白），不是炫富道具 |
| **拜师** | 退役传奇选手 / 赌场老人，**看出他「不是运气好」** | 师父本身是伏笔（他知道系统的存在？他为什么退役？）。师徒关系要有冲突，不是单方面给资源 |
| **财富** | 电竞奖金 → 预测咨询 → 金融 → 公司 | **每一步都有合法来路**。写税务、写合同、写风险，不写「一夜暴富」 |

**铁律**：任何一个爽点出现前，先问「它从哪来？为什么合理？」答不上来就删掉。

## 7. 逻辑硬约束（**审查时按这五条查，不许为了爽放弃**）

| # | 约束 | 怎么查 |
|---|---|---|
| L1 | **能力不无限用** | 每次使用是否有次数/精力/代价描写？ |
| L2 | **不被发现** | 主角是否有表演/借口/低调动作？系统是否有「遮蔽」设定？ |
| L3 | **假赛不被查** | 是否只在关键局用？是否是心理/状态层面而非明显放水？ |
| L4 | **财富合法** | 奖金/咨询/投资是否有合同、税务、风险描写？ |
| L5 | **感情合理** | 女方是否有共同经历 + 能力认可 + 人格吸引？有无无脑倒贴？ |

**外加一条**：任何「巧合」超过 2 次，必须变成「布局」。**巧合是伏笔没写好的表现。**
