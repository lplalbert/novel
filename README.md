# 网文工作区

> 多本书共用的写作工作区。**每本书一个独立目录**，通用资料放根目录。

---

## 目录结构

```
novel/
├── README.md              ← 本文件
├── 写作风格/               ← 跨书通用：你的文风、禁用词、写作备忘
│   ├── 文风样本.md         ← 你的代表段落（每次生成前喂给 AI）
│   ├── 禁用词清单.md       ← AI 味高频词，写完自己过一遍
│   └── 写作备忘录.md       ← 你的写作原则、经验、待办
├── 备忘录/                 ← 跨书通用：方法论、调研、提示词
│   ├── AI辅助网文创作流程-调研.md
│   ├── 提示词库.md
│   ├── 执行计划.md
│   ├── 选题候选-通用12例.md
│   └── .research/          ← 调研原始素材
└── 书01-金铲铲/            ← 第一本书
    ├── README.md           ← 本书状态、进度、下一步
    ├── 01-概念与系统设定.md
    ├── 02-一句话卖点.md
    ├── 03-人物卡.md
    ├── 04-总纲与分卷.md
    ├── 05-伏笔账本.md      ← 每 30 章盘点一次
    ├── 06-设定词典.md      ← 名词/设定，防崩文
    ├── 07-选题记录-云顶金铲铲.md
    ├── 细纲/
    │   ├── 卷1/
    │   │   ├── 1-1.md      ← 每个小阶段一个文件
    │   │   └── ...
    ├── 章纲/               ← 每章三要素（只写下一章）
    ├── 正文/               ← 001.md、002.md ...
    └── 审查记录/           ← 每章的审查清单 + 修改决定
```

## 版本管理

**用 git**。建议提交节奏：

| 时机 | 提交信息示例 |
|---|---|
| 每章初稿完成 | `书01: 第3章初稿` |
| 每章改完 | `书01: 第3章改稿 + 审查记录` |
| 大纲/设定变更 | `书01: 卷1细纲 1-1` |
| 跨书通用资料变更 | `备忘录: 更新提示词库` |

**为什么用 git**：
1. 大纲会反复改，要有版本历史
2. **改稿记录是创作证据**（版权 + 平台申诉都要）
3. 写崩了能回滚

## 写作流程（每章循环）

```
1. 章纲（三要素：开局状态 / 核心事件 / 结尾钩子）
   ↓ 人定（AI 出 3 个方向挑）
2. 你写初稿（1500-2500 字）
   ↓ AI 完全不碰
3. AI 出审查清单（不代笔）
   ↓
4. 你按清单自己改
   ↓
5. 存正文/00X.md + 审查记录/00X.md
```

**红线**：AI 不写正文；永远不说「帮我润色一下」。
