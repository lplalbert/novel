# 禁用词清单（AI 味检测表）

> 写完每一章，**自己过一遍**这张表。AI 出审查清单时也会标，但**你自己扫一遍最快**。
> 原则：**改味不改错**——只改怎么说，不改说什么。**删除上限：轻度≤15%，中度≤25%，重度≤35%**。

---

## 一级禁用（见到就删/换）

| 词/句式 | 修法 |
|---|---|
| 不禁 | 删 |
| 仿佛 / 犹如 / 宛若……一般 | 删掉或白描 |
| 映入眼帘 | 删 |
| 心中暗道 | 他心想 / 直接写心理 |
| 沉声道 | "……" 他声音发紧 |
| 嘴角微扬 / 嘴角勾起一抹 | 他嘴角一扯 / 他笑了 |
| 不由自主 | 删 |
| 只见 | 删 |
| 眼中闪过一丝…… | 他垂下眼 / 他眼皮一跳 |
| 心中涌起一股…… | 用身体反应（手抖、心口发紧） |

---

## 二级禁用（★越多越毒）

| 毒级 | 句式 | 修法 |
|---|---|---|
| ★★★★★ | "不是A，（而）是B" | **直接写 B** |
| ★★★★ | "，带着……" 万能状语 | 删状语留主句 |
| ★★★★ | "声音不大，却带着……" | 直接写台词/动作 |
| ★★★★ | "他/她知道……" | 用行为展示认知 |
| ★★★ | "仿佛/犹如/宛若……一般" | 删或白描 |
| ★★★ | "眼中闪过一丝……" | 用动作 |
| ★★★ | "心中涌起一股……" | 用身体反应 |
| ★★ | 章末"他不知道的是……" | 用具体钩子物件收束 |

---

## 章末禁忌

- ❌ 总结式收尾（"他明白了一个道理……"）
- ❌ 升华感叹（"这就是成长"）
- ✅ 用动作 / 对话 / 悬念收束

---

## 结构性 AI 味

| 症状 | 怎么破 |
|---|---|
| 三连排比 | 打散重写 |
| "不难看出 / 由此可见 / 综上所述" | 删 |
| 每段首尾都是连接句（于是/然而/此刻） | 删掉一半连接句 |
| 所有角色说话一样"高级" | 区分语气（见下） |
| 句子长度均匀 | 长短句交错，按情绪 beat 调 |
| 连续 3+ 句同一主语开头 | 换主语 |

---

## 情绪外化对照（**最重要的一条**）

| ❌ 告诉 | ✅ 展示 |
|---|---|
| 他感到一阵紧张 | 他攥紧了手里的纸杯，水洒出来一些 |
| 愤怒在他心中燃烧 | 他把筷子往桌上一拍，碗里的汤溅了出来 |
| 一丝悲伤涌上心头 | 她低头搅着咖啡，搅了很久 |
| 终于明白了生活的真谛 | 他把烟掐了，回屋睡觉。 |
| 他很疼 | 他弓着背，手撑着桌沿，半天没直起来 |
| 她很担心 | 她把手机翻过来又翻过去，屏幕亮了又暗 |

**口诀**：
```
一事一段，镜头自然断。
对话要像人说话。
心情不写心里话。
结尾不搞大升华。
打斗不写流水账。
日常要埋伏笔桩。
```

---

## 每章自检清单

```
□ 段落按动作/信息变化断开，读起来不卡
□ 无一级禁用词
□ 无三连排比、无"不难看出/由此可见"
□ 章尾无总结升华
□ 大段心理描写不超过 2 段
□ 关键情绪用身体反应展示，不用情绪形容词
□ 对话口语化，不同角色语气可区分
□ 有一个细节是这个场景特有的？
□ 删掉任何一句会影响理解吗？不会 = 多余
□ 结尾钩子够不够（读者会不会点下一章）
```
