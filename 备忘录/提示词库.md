## 0. 开书第一条请求

**核心心法：不要让 AI 自动写正文。题材取舍、角色动机、长期方向必须你自己确认。**

```text
我想开一部〈类型/题材〉新书。先从我提供的材料中分开已确定事实与待决问题；
只规划一个有边界的开篇，交付核心冲突、视角/信息释放限制、前三章变化和待决项。
不要自动写正文；题材取舍、角色动机和长期方向留给我确认。
```

改稿时用这条（**不要全书改写**）：

```text
这段读起来〈空泛/重复/过度解释〉。先指出具体读感问题，保留故事事实、角色已知和未揭示边界；
只交付这一段的修订建议、前后对照与理由，不全书改写。哪些建议采用由我决定。
```

## 1. 选题决策

### 1.1 选题四步（缺一不可）

| 步骤 | 做什么 | 产出 |
|------|--------|------|
| 1. 能爆的原因（先当假设） | 从榜上**重复出现的样本**（排除单本个例）+ 新元素，推出「靠 X 结构/梗/人设吃这波读者」 | 假设句，标 `待拆文验证` |
| 2. 市场验证 | 同方向有几本上榜 + 趋势（↑/→/↓）+ 反例（有没有扑街/烂尾） | 样本数与趋势 |
| 3. 差异化定位 | **作者优势 × 市场缺口** = 你的版本和榜上现有的不同在哪 | 一句话差异化 |
| 4. 可行性 + 风险 + 验证动作 | 高/中/低三档 + 最可能崩的点 + 开写前低成本验证 | 「先写黄金三章测追读，不行就换」 |

**可行性硬规则**（防假信心）：
- **高**：同方向榜上样本 ≥15（小平台 ≥10）+ 趋势↑或→ + 作者素材能撑 + 有差异化空间
- **中**：样本够但趋势↓ / 差异化不清 / 素材半撑
- **低**：已饱和 / 素材撑不住 / 平台调性不符
- **无榜单数据时一律只给「中」，禁止给「高」**

### 1.2 选题决策模板

```markdown
# 选题决策：{平台/方向}
- 扫榜日期：{YYYYMMDD}
- 数据来源：{榜单文件名 / 内置知识}

## 推荐选题

### 选题 1：{一句话方向}
- 题材组合：{主类型 + 副类型/梗}
- 目标读者：{画像}
- 核心卖点：{读者为什么追}
- 能爆的原因：{X 结构/梗为什么吃这波}（假设，`待拆文验证`）
- 差异化定位：{和榜上现有的不同在哪}
- 可行性：高/中/低 — {理由，写清同方向几本 + 趋势}
- 失败风险：{最可能崩在哪}
- 验证动作：{开写前怎么低成本验证}
- 篇幅/平台：{建议字数区间 + 目标平台}
```

2-3 个选题为宜，按可行性排序。

### 1.3 金手指设计三类内核

| 类型 | 说明 | 可控性 |
|------|------|--------|
| **信息挂**（最优） | 穿越重生记忆、剧透、读心、鉴定 | 不易失控 |
| 加速升级挂 | 经验加成、熟练度面板、时间流速 | 中 |
| 物体/系统调用挂 | 随身空间、召唤、商城 | 容易失控，需严格限制 |

**核心原则**：
- 金手指决定本书基调
- 金手指太强 + 矛盾不够 = 无聊；太弱 + 矛盾太强 = 读者焦虑
- **最佳曲线：金手指刚好解决当前矛盾 → 暴露更大矛盾 → 层层递进**
- 必须与主角生活/职业息息相关（医生配医术=合理；医生配隐身=牵强）
- 一个技能衍生不同效果，**不要频繁开新金手指**
- 游戏化面板一眼就懂最好

**核心梗 = 金手指最核心的使用方式 + 读者最想看的爽点模式**

每章必备三选一：①核心梗相关期待点 ②核心梗相关爽点 ③两者之间。
**既无期待也无爽 = 断期待 = 弃书。**

### 1.4 Logline 公式

**通用（编剧社区通行）**：
> 当【意外事件】发生时，一个【身份/缺陷】的【主角】必须【目标】，否则【赌注】。但【核心障碍/对手】。

**网文版（更强调金手指+爽点）**：
> 【身份反差的主角】+【金手指】+【核心冲突】+【爽点模式】

**书名 3 秒抓人四法**：身份法（约 1/3 书名）、掉马甲、反义词法、主线+爽点法

**三位一体**：书名暗示的卖点 = 简介承诺的内容 = 正文实际交付。货不对板直接劝退。

## 2. 人物卡（含动机链）

### 2.1 主角卡

```text
姓名：
性别：
角色定位：（一句话说清主角在故事中的功能）
身份标签：（如：废柴大学生、前特种兵、落魄皇子）
外貌特征：（3-5 个关键词，要有记忆点）
  例：瘦高、总穿旧夹克、左手有疤、眼神懒散
性格关键词：（3-5 个，必须有矛盾面）
  例：嘴毒心软、看似冷漠实则护短、冲动但有底线
核心目标：（全书终点想达成什么）
核心动机：（必须达成的理由——情感驱动，非理性驱动）
致命弱点：（让角色犯错的性格缺陷，非能力缺陷）
口头禅/标志动作：（让读者秒认的标签）
```

### 2.2 动机链（人物小传的灵魂，比身高体重重要）

```text
起因（Cause）    → 角色经历了什么
                  （必须具体："被欺负"不够，"在众目睽睽下被打耳光"才行）
意图（Intent）   → 角色想做什么（区分表面意图与真实意图）
约束（Constraint）→ 什么在阻碍他（外部+内部）
风险（Risk）     → 失败的代价是什么
                  （读者要相信角色真的可能失去重要的东西）
```

### 2.3 三层标签反差人设法

```text
第一层 身份标签：外界看到的身份（豪门弃妇）
第二层 表现标签：角色展现给外界的行为（隐忍不发、逆来顺受）
第三层 内核标签：角色真正的内心（冷静、有计划、步步为营）
→ 用行为对比体现反差，不要直接描述
```

### 2.4 配角卡

```text
姓名：
性别：
角色功能：（导师/盟友/情报源/牺牲品/镜像对照）
与主角关系：
核心特质：（1-2 个关键词）
标志性特征：（一句话让读者记住）
退场方式：（何时/如何退出故事）
```

### 2.5 角色语言 7 维差异化

口癖、说话节奏、信息偏好、立场固定、身份措辞、性格语气、关系进度

## 3. 大纲模板

### 3.1 分层大纲（网文最适配）

```
总纲：全书主线、核心设定与整体走向
  └ 卷纲：1 卷 = 10 故事 = 1 大高潮
       · 卷契约（本卷承诺给读者什么爽感/期待）
       · 本卷主推线 / 战果 / 伏笔 / 反转
       · 剧情单元卡（1-3 万字）
       · 核心矛盾（一句话）/ 情绪弧线 / 人物弧线
  └ 章纲：每章三要素 + 钩子
       · 本章定位 / 核心事件 / 情绪曲线
       · 爽点 / 伏笔钩子 / 角色状态变化
```

**细纲:正文 ≈ 1:2.5 ~ 1:3**

**每章硬规则**：
- 章首必须有进入本章的拉力（不必章章硬钩子）
- 每章执行「**收一个、变一个、开一个**」
- 每章必须有情绪变化（标注起点→终点，如「平静→震惊→愤怒」）
- 黄金三章钩子强度是硬下限

### 3.2 五步大纲创建法

1. **确定高潮剧情**（绝对优先级：最大冲突、最多人物、最强情绪）
2. **确定单元剧**（每个单元 = 金手指优势获得爽点；相邻单元禁止相同金手指逻辑）
3. **八条故事线组织**（地图/阵营/人物/金手指/世界观/矛盾/收集/感情）
4. **确定开篇舞台**：情节钩子 → 异常状态 → 金手指 → 矛盾/欲望 → 目标建立
5. **确定收尾**（解决高潮 + 奖励 + 下卷铺垫）

### 3.3 大纲文件模板

```markdown

- **预计章节数**：
- **目标字数**：每章 X 字，总计 X 万字
- **核心冲突**：[主角想要什么？什么阻止了他？]

|-----|------|---------|---------|-------------|---------|---------|------|
| 第1章 | | | — | | | |

## 全书悬念线
- **主线悬念**：
- **支线悬念**：
- **终极揭秘**：

## 设定词典

| 名词 | 首现章节 | 读者已知 | 完整真相 | 计划揭示 |
|------|---------|---------|---------|---------|
```

## 4. 章节写作

### 4.1 逐章创作指令

```text
你是一个小说章节撰写 Agent。为我创作第 {N} 章。

## 写前必读
1. 读大纲中本章的：核心事件、承接上章、悬念钩子、出场人物、场景列表
2. 核对设定词典：首现名词须给上下文线索；已介绍名词不得超出「读者已知」
3. 提取出场角色的：性格核心、致命缺陷、说话风格/口头禅、恐惧/弱点、人物关系
4. 读上一章结尾 500-800 字，把握衔接语态和情绪落点
5. 动笔前最后读到的必须是正文语态文字（上一章结尾 + 文风基准段落），
   不要让大纲表格成为最后上下文

## 撰写要求
- 字数：{平台字数}
- 章首引子：50-150 字（悬念对话/闪前碎片/倒计时/神秘独白/反差场景/未完成动作/意象预示）
- 正文开头第一段：必须建立即时冲突，禁止从背景介绍/天气/风景开始
- 张力：全章至少 2 个张力波峰，连续 500 字以上无冲突时引入新张力
- 对话：至少 30% 对话内容，每段对话必须有潜台词或推进情节目的
- 意外转折：每章至少 1 个读者预期之外的事件或信息
- 人物一致性：行为严格符合角色设定
- 结尾钩子：突然揭示/紧急危机/未完成动作/身份反转/两难抉择/神秘物品/倒计时
- 章末禁止：总结感悟、升华感叹、哲理收尾、"他不知道的是……"式预告

## 输出格式
本章概要 / 章首引子 / 正文 / 章节备注（悬念、下章预告、伏笔标记、新名词登记）
```

### 4.2 章首引子七式

悬念对话 / 闪前碎片 / 倒计时 / 神秘独白 / 反差场景 / 未完成动作 / 意象预示

### 4.3 结尾钩子清单

突然揭示 / 紧急危机 / 未完成动作 / 身份反转 / 两难抉择 / 神秘物品 / 倒计时 / 承诺威胁 / 离奇消失 / 隐藏含义 / 意象 / 回声 / 留白

## 5. 去 AI 味

### 5.1 核心信念

> AI 味的主要问题**不是语法错误**，而是**过度圆滑、工整、解释充分**。
> 改写目标是保留剧情功能，同时增加口语、停顿、跳跃和具体动作。

**四原则**：
1. 改味优先，别当改错
2. **改最少，效果最大**（能改一个词就不改一句；删除上限：轻度≤15%，中度≤25%，重度≤35%）
3. **保留创作意图**（只改"怎么说"，不改"说什么"；剧情、人设、情节走向一概不动）
4. 按文风保留有功能的语气与停顿

### 5.2 三遍法

**Pass 1：去泛化（去掉 80% 的 AI 味）**
- 抽象情绪总结句 → 删或换成具体动作
- 假深度句 / 空洞结论 → 删
- 意义膨胀 → 缩小到具体影响
- 工整对比句式 → 打散重写
- 装饰性形容词堆砌 → 白描
- "于是/然而/此刻" → 删掉一半
- 所有角色说话一样"高级" → 区分语气

**Pass 2：去书面化**
- "机制/结构/逻辑/体系" → 日常表达
- 抽象名词滥用 → 直接说事
- "进一步/深入/推进/落实" → 删

**Pass 3：回自然感**
- 具体感官细节（气味、温度、触感）
- 角色说话方式区分
- 句首变化（连续 3+ 句同一主语开头就换）
- 长短句交错，按情绪 beat 调节
- 社会位置感（上下级说话方式不同）
- 角色口头禅

**少即是多：每段加 1-2 个具体细节就够了。**

### 5.3 情绪外化对照

| ❌ 告诉 | ✅ 展示 |
|---|---|
| 他感到一阵紧张 | 他攥紧了手里的纸杯，水洒出来一些 |
| 愤怒在他心中燃烧 | 他把筷子往桌上一拍，碗里的汤溅了出来 |
| 一丝悲伤涌上心头 | 她低头搅着咖啡，搅了很久 |
| 终于明白了生活的真谛 | 他把烟掐了，回屋睡觉。 |

### 5.4 可复制的润色指令

```text
请把下面这段网文正文做去 AI 味润色。要求：

【只改表达，不改剧情】
- 剧情、人设、情节走向、伏笔、时间线一概不动
- 不新增原文没有的情节/设定/关系
- 改最少的字，让整段"味"变过来

【删除/替换】
1. 抽象情绪总结句 → 用身体反应/动作外化（不写"他很紧张"，写"手心全是汗"）
2. AI 高频词：仿佛/犹如/不禁/眼中闪过/嘴角勾起/心中涌起/深吸一口气/缓缓/一丝/一抹
3. "不是A而是B"、"，带着……"、"声音不大却……"、"他感到/他知道……"
4. 章末总结升华、哲理收尾、"他不知道的是……"式预告 → 用动作/对话/具体钩子收束
5. 连续排比、工整对仗 → 打散

【保留/加强】
- 角色口语、俚语（符合身份）、语气词
- 具体感官细节（气味/温度/触感）
- 不同角色说话方式区分
- 长短句交错，按情绪节奏
- 有功能的标点（质问的？、爆发峰值少量！）

【输出】
1. 修改后正文
2. 修改点列表（原文 → 改后 → 理由）
3. 标注 [需复核] 的疑似问题句（不确定就标，不要硬删）
```

## 6. 禁用句式表

| 毒级 | 句式 | 修法 |
|------|------|------|
| ★★★★★ | "不是A，（而）是B" | 直接写 B |
| ★★★★ | "，带着……" 万能状语 | 删状语留主句 |
| ★★★★ | "声音不大，却带着……" | 直接写台词/动作 |
| ★★★★ | "他/她知道……" | 用行为展示认知 |
| ★★★ | "仿佛/犹如/宛若……一般" | 删掉或白描 |
| ★★★ | "眼中闪过一丝……"/"嘴角勾起一抹……" | 他垂下眼 / 他嘴角一扯 |
| ★★★ | "心中涌起一股……" | 用身体反应 |
| ★★ | 章末预告 "他不知道的是……" | 用具体钩子物件收束 |

**一级禁用词**：不禁 / 仿佛 / 映入眼帘 / 心中暗道 / 沉声道 / 嘴角微扬 / 不由自主 / 只见

## 7. 每章自检清单

```text
□ 段落按动作/信息变化断开，读起来不卡
□ 无 AI 高频词（见上表）
□ 无三连排比、无"不难看出/由此可见/综上所述"
□ 章尾无总结升华（用动作/对话/悬念收束）
□ 无大段心理描写（心理活动不超过 2 段）
□ 关键情绪用身体反应展示，不用情绪形容词
□ 对话口语化，不同角色语气可区分
□ Show Don't Tell：用行为代替形容词
□ 有没有一个细节是这个场景特有的？
□ 删掉任何一句会影响理解吗？不会 = 可能多余
```

**口诀**：

```text
一事一段，镜头自然断。
对话要像人说话。
心情不写心里话。
结尾不搞大升华。
打斗不写流水账。
日常要埋伏笔桩。
```

## 8. 同质化怎么破

**根源**：让 AI「随便写」→ 落入训练分布均值；无文风基准 → 风格漂移；只喂大纲不喂「怎么说」→ 默认书面腔。

| 技巧 | 怎么做 |
|------|--------|
| **文风基准文件** | 从自己写的/最喜欢的段落选 600-1000 字做「基准段落」，每次生成前喂给 AI |
| **角色语言 7 维** | 口癖、节奏、信息偏好、立场、措辞、语气、关系进度 |
| **70/20/10 素材法** | 70% 个人经历 + 20% 当前生活 + 10% 热点 |
| **Few-shot 而非形容词** | 不要写「文风像余华」，要贴 3-5 段原文样例 |
| **少即是多改写** | 去 AI 味「改最少的字」，别整段重写 |
| **反投机边界** | 不为「反检测」强行换行/改标点/删所有「的了地得」——去 AI 味是润色不是结构重写 |
| **私人表达预算** | 非核心情绪的个人表达 ≤ 全篇 5%，且必须服务核心卖点 |
| **模仿的正确方向** | 模仿：故事套路/戏剧手法/叙事结构/角色类型。**不要模仿**：文辞/经典桥段/语言风格 |

## 9. 微创新五法（创新点最多 3 个）

| 手法 | 核心 | 示例 |
|------|------|------|
| 精炼法 | 把已有套路做到极致 | 打脸一巴掌→三巴掌层层递进 |
| 升级法 | 框架不变元素升级 | 「校花」→「国民校花+学霸+隐藏身份」 |
| 加料法 | 已有框架加新元素 | 重生+规则怪谈，种田+末日 |
| 反套路法 | 反过来写 | 废材逆袭→天才跌落重新站起 |
| 组合法 | 两个不相干套路组合 | 种田+修仙，系统+悬疑 |

**检查清单**：创新点≤3？在模板边界内？不影响读者核心期待？有素材支撑？没增加太多创作难度？

**题材阶段判断**：新鲜期优先创意；成熟期稳定交付边界期待；疲劳期必须新切入点；无法确认时按成熟期处理。
